# Уменьшение размера и памяти Forkop X и Xrust

Базы рабочих деревьев — Forkop `18648dae` и Xrust `94df45c`. Парные измерения и испытания пакетов проводились на рабочих снимках, включавших ранее подготовленные локальные изменения. Приведённые размеры относятся к этим сборкам. Сборка клиентского ядра использует профиль `forkop-client`.

## Что изменилось

| Компонент | Результат |
|---|---|
| DNS и правила | Таблицы FakeIP и ответов DNS растут по мере заполнения с прежними пределами LRU. Индекс CIDR освобождает строительный массив и собирает готовые корзины по длине префикса. Индекс ключевых слов освобождает промежуточный вектор. |
| Транспорты | Общий H2-пул создаётся у типов gRPC и HTTP. XHTTP продолжает использовать свой пул. В XHTTP H1 при закрытии последней сессии клиента с исчерпанным лимитом освобождаются его свободные POST-сокеты. WebSocket использует малый буфер заголовка и читает данные в буфер вызывающей стороны. Tailscale и MASQUE используют общий для потока приёмный буфер UDP по примеру WireGuard. |
| TLS и Clash API | Обычные TLS-конфигурации разделяют стандартное хранилище доверенных корней. Пользовательские сертификаты сохраняют прежнюю семантику замены или дополнения корней. Clash находит соединение по числовому ID, а в полном снимке переносит готовый массив в ответ. |
| Чтение конфигурации и SRS | Объединённый JSON передаётся в ядро уже разобранным. SHA-256 конфигурации и деклараций наборов считается при сериализации в поток. Определение TSRS и загрузка используют один открытый файл. При восстановлении remote-набора убрана копия записи; для штатного HTTP 304 обновляются восемь байт времени. Учёт отложенной записи и условия flush сохранены. |
| Клиентский ELF | У regex отключён one-pass DFA. В клиенте сохранены bounded backtracker, hybrid DFA, Unicode и поиск литералов. Из клиентского профиля исключены таблицы проверки серверных inbound. Обработка ошибок Win32 в CLI ограничена Windows. |
| Backend Forkop | Новый кэш ucode разделяет совпадающие готовые файлы с предыдущим поколением через hardlink после проверки интерпретатора, содержимого и атрибутов. Ошибка создания ссылки оставляет готовую копию. Watchdog ждёт встроенным sleep. При сравнении подписок хранятся счётчики канонических записей одной стороны. Восстановление кэша и hot reload избегают повторного разбора полного JSON. |
| LuCI | Минифицируются внутренние идентификаторы, а публичные имена берутся из списка экспортов сборщика. Для диагностических сообщений используются устойчивые к переименованию коды проверок. |

## Проверка совместимости

При повторном ревью исправлены два случая обработки сохранённых remote-наборов. Запись прежней версии с распознаваемым форматом при HTTP 304 переводится в текущий формат. Если в записи повреждена только метка времени и она выходит за диапазон системных часов, ядро использует проверенное содержимое офлайн и планирует обновление.

В парной сборке Xrust с Rust 1.100.0 ARM ELF уменьшился с 7 254 016 до 7 236 832 байт. Для Cortex-A53 IPK уменьшился с 3 690 162 до 3 677 485 байт, неподписанный APK с 3 694 583 до 3 683 030. Использовались одинаковые параметры компоновки и упаковки. Проверены длины и SHA-256 шести ARM-пакетов каждого варианта. ARM ELF проверен статически; тесты с работающим ядром проходили на x86_64. В WSL отсутствовал QEMU AArch64.

В проверке regex на версиях из Cargo.lock каждый прогон выполнял 1 056 000 операций is_match. Медианы пяти прогонов составили 12,171 мс у исходного варианта, 14,095 мс при отключении обоих движков и 11,841 мс при отключении только OnePass. Число совпадений по каждому шаблону совпало. Двойное отключение замедлило этот сценарий на 15,8%, поэтому в итоговом клиенте сохранён Backtrack.

В трёх парах холодных запусков Linux x86_64 (один worker, 512 синтетических узлов VLESS, двухстековый FakeIP, без трафика) медиана VmRSS снизилась с 33 900 до 31 952 КиБ, RssAnon — с 13 748 до 11 620 КиБ. Обе версии собраны в одном каталоге с одинаковым dev-профилем. Измерялся процесс Xrust в WSL. На рабочем MT6000 величина эффекта остаётся неизвестной.

На одной исходной базе собраны два варианта LuCI. Размер `main.js` уменьшился с 458 500 до 345 144 байт, APK с 239 881 до 224 898 байт, IPK с 240 908 до 226 268 байт. Проверены распакованные пакеты, 35 экспортов, четыре вкладки, 663 теста фронтенда, первоначальный рендер и обработчик сохранения. Edge использовал настоящий загрузчик LuCI с тестовыми модулями RPC. При подготовке коммита LuCI повторно собран из 18648dae с двумя изменениями исходников этой серии. На этой базе main.js уменьшился с 459 626 до 345 893 байт, прошли 662 теста и проверка 35 экспортов в Edge.

На Linux проверены конкурентная сборка и сбой компилятора ucode, сохранение старого поколения, байтовое сравнение файлов, включая нулевые байты, и различающиеся права. Проверки подписок охватили дубликаты и перестановки. Для hot reload проверены отказ при повреждённом JSON, revalidation, старый контроллер и явно указанный тег. В трёх повторах для подписок на 70 и 1 500 узлов снижение пикового RSS отдельного процесса оказалось в пределах разброса. Тесты релизного каталога и подписи прошли на локальных фикстурах (5 и 25 соответственно).

На VMware OpenWrt 25.12.6 x86_64 развернули в отдельном дереве исходные и новые модули, удерживали старый helper до следующего запуска и повторили смену поколений в обратную сторону. В каждом случае helper успешно загрузил прежний модуль, а новая CLI — текущий. В двух поколениях 84 файла разделили inode, экономия по блокам tmpfs составила 1 324 КиБ. В трёх проверках у ожидающего watchdog отсутствовали дочерние процессы, остановка заняла не более секунды. После удаления тестового дерева сверены версии пакетов, состояния служб, PID, DNS и контрольные суммы. Установленные пакеты VM оставались Forkop/LuCI 3.0.9 и rust-x 0.0.51-r1. На финальном кандидате также проверены замена интерпретатора во время компиляции, 24 последовательных обновления кэша и hot reload через настоящий Xrust с подтверждением и отказом. После каждой смены сохранялись два поколения и две ссылки на неизменившийся файл. После уборки общая занятость tmpfs VM была на 4 КиБ выше исходной, причину разницы установить не удалось. Пакетные транзакции проверены отдельно ниже.

Проверка повторных reload проходила с открытым TCP-соединением SOCKS к локальному echo-серверу. Приняты 12 изменений конфигурации и отклонены 12 ошибочных. После каждого сигнала проверялись двусторонние данные, список соединений и запрос по ID. У процесса было 11 FD до соединения, ровно 17 в каждом из 24 циклов и снова 11 после закрытия. Отпечатки одиночного файла и эквивалентного каталога конфигурации совпали. Проверены также FakeIP вплоть до вытеснения, восстановление ранее записанной базы после рестарта, TLS, regex, mmap/TSRS, XHTTP H1 и клиентский отказ для серверного inbound. Это проверка повторяемого сценария, её продолжительность ограничена.

## Обновление и откат через пакетный менеджер

На обеих x86_64 VM установили четыре тестовых пакета (Forkop 3.0.11-canary.1, LuCI, русский перевод, Xrust 0.0.53), затем вернули исходные версии через тот же пакетный менеджер. Проверки выполнены до восстановления снимков VMware.

| VM | Исходные Forkop / Xrust | Результат |
|---|---|---|
| OpenWrt 24.10.8, opkg/IPK | 3.0.2-canary.99 / 0.0.45-1 | Работающий сервис автоматически восстановился при обновлении и понижении версии. Проверены хэш исполняемого файла работающего Xrust, DNS, HTTP-ответ LuCI, а также 109 → 116 → 109 пакетных файлов и их режимы. |
| OpenWrt 25.12.6, apk | 3.0.9 / 0.0.51-r1 | Изначально остановленный сервис остался остановленным. На исходной, новой и возвращённой версиях отдельный экземпляр установленного Xrust доставил файл LuCI через SOCKS5 с побайтовой проверкой. Локальный DNS работал. Для возврата использовались подписанные исходные APK. |

Штатное понижение версии сохранило часть служебного состояния. На VM25 изменилось единственное поле UCI Forkop `shutdown_correctly`. На VM24 сохранились изменённые `applied_migrations`, `forkop_dns_transaction_id`, перегенерированный конфиг Xrust и маркер отложенной проверки задержки. Затем обе VM вернули к исходному состоянию через снимки, сверили контрольные суммы и оставили запущенными. Временные снимки удалены.

## Что осталось экспериментальным

Пропуск опроса скрытой вкладки теряет историю завершившихся соединений, а кэширование адреса контроллера между вызовами CLI требует надёжного способа обнаруживать смену адреса. Оба пути сохранили прежнее поведение.

Изменение окон WG/TUN, общей политики удержания UDP и лимитов повторного использования живых H1/QUIC-соединений требует измерений потерь, RTT и пропускной способности. Ленивый дисковый доступ к телам bbolt требует отдельной проверки атомарной перезаписи неизвестных buckets и восстановления после ошибки. Изменение раскрутки стека, RELR, параметров компилятора, сокращение путей сборки и замена реализаций криптографии/Хаффмана остаются отдельными экспериментами. Адаптация буферов H2 уже входила в базовый Xrust.
