# Описания выпусков — для обсуждения

Публикация пока не согласована. Forkop X готовится как 2.6.0 без canary,
Xrust — как 0.0.29.

Описания приведены к стилю опубликованных Forkop X 2.5.0 и Xrust 0.0.28:
русский язык, тематические разделы `##` и короткие пункты об изменениях.
В самих описаниях нет заголовка версии, служебной отметки о черновике
и подробного отчёта о тестах.

- Forkop X: [описание 2.6.0](releases/2.6.0.md).
- Xrust: `docs/releases/0.0.29.md` в ветке dev репозитория Screamshow/xrust.
- Запись в changelog Zapret Manager не добавляется. Его `CHANGELOG.md`
  остаётся без изменений.

В описании Forkop явно указан переход от встроенных правил Zapret/Zapret2
к отдельному менеджеру: старые правила отключаются и переводятся в bypass,
а их стратегии автоматически в менеджер не переносятся. Сохранено уточнение
об отсутствии аппаратной проверки Rockchip и MT7628AN. Для MT7628AN добавлены
пакеты `mipsel_24kc`; отдельно оговорены требования к свободной flash и RAM.

Технические результаты находятся отдельно в
[отчёте подготовки](dev-260-preparation-2026-10-29.md).

Порядок после согласования: менеджер и его зеркало -> Xrust и его зеркало ->
проверка локального Forkop 2.6.0 с настоящими публичными источниками на VM ->
Forkop X 2.6.0 и стабильное зеркало. Пользовательские роутеры не затрагиваются.
