# Описания выпусков — для обсуждения

Не публиковать до согласования с пользователем. Forkop X выпускается как
2.6.0 без canary. Запланированный Xrust — 0.0.29. У менеджера финальная версия
ещё не согласована: 4.71.1 — номер тестовой панели, 9.90.1 — загрузчика.

## Zapret Manager

Очищенный Zapret Manager для Forkop: пять разделов — Дашборд, Zapret, Zapret2,
Hosts и Терминал. Консоль, LuCI и Web UI используют общий backend. Сохранены
стратегии, тесты и восстановление стратегий, пользовательские списки и настройки.
Из панели удалены исключённые компоненты; самостоятельно установленные
сторонние службы остаются на устройстве.

Обновления панели и консольных загрузчиков направлены на Screamshow через
зеркало Forkop, с резервным источником в нашем GitHub. Добавлен контракт для
проверяемой миграции старых установок через Forkop X.

## Xrust 0.0.29

Добавлены APK/IPK для OpenWrt `aarch64_generic` — архитектуры Rockchip/ARM64,
включая устройства на RK3528A, RK3566, RK3576 и RK3588 с соответствующей
64-битной прошивкой. Другие архитектуры сохранены. Обновлены проверки пакетов,
подписи и каталог версий зеркала.

Пакеты собраны и проверены. На x86 VM пройдены установка и возврат версии
через Forkop, а также автоматический откат после ошибки запуска. Доступа к
Rockchip не было: аппаратная проверка на этих устройствах ещё ожидается.

## Forkop X 2.6.0

Основной черновик: `releases/2.6.0.md`. В описание войдут миграция старого
менеджера с сохранением состояния и откатом, установка Xrust для
`aarch64_generic`, а также уже подготовленные в dev исправления и изменения.

Обязательно явно описать удаление встроенных правил Zapret/Zapret2:
старые правила отключаются и переводятся в bypass, а не автоматически
преобразуются в стратегии отдельного менеджера. При отсутствии менеджера
Forkop не устанавливает его сам.

Порядок после согласования: менеджер и его зеркало -> Xrust и его зеркало ->
проверка локального Forkop 2.6.0 с настоящими публичными источниками на VM ->
Forkop X 2.6.0 и стабильное зеркало. Пользовательские роутеры не затрагиваются.
