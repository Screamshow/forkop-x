## Подписки и ручной импорт

- LuCI принимает ссылки Hysteria2 без порта и использует `443`.
- Исправлен импорт `+` и `%2B` в паролях Trojan и Hysteria2. Пароли в кеше восстанавливаются из исходных ссылок.
- Из подписок в YAML импортируются список портов, `hop-interval`, SHA-256-пин `fingerprint` и имя проверки сертификата `name-cert-verify` для Hysteria2.
- При ручном импорте WebSocket без пути используется `/`. В ссылках Trojan параметр `peer` используется как SNI, если `sni` не задан.
- Импорт и экспорт сохраняют TLS-пины Xray, `vcn`, режим gRPC `multi` и отдельное подключение XHTTP для загрузки.
- XHTTP без `security` включает TLS, если в ссылке указаны параметры TLS.

## Применение настроек и DNS

- Фоновое обновление подписок сохраняет запрос на применение настроек LuCI.
- Переключение на резервный DNS использует конфигурацию запущенного ядра, включая настройки туннелей, которые наследуют общий резолвер.
- Улучшен откат конфигурации ядра и DNS при сбое применения.
- Исправлена проверка маршрутов и правил TProxy для IPv4 и IPv6.

## Кеш, LuCI и диагностика

- Узлы подписки, параметры запроса и метаданные кеша записываются одной операцией.
- Ручной замер задержки доступен между фоновыми попытками. Запросы к Clash API ограничены таймаутом.
- Проверки Priority чередуются между группами, чтобы перебор узлов одной группы меньше задерживал остальные.
- Мониторинг LuCI обновляет условия маршрутизации после применения конфигурации ядра.
