## Установка и обновление

- Исправлена ошибка установки прокси-ядра на OpenWrt 24.10, когда зависимость `libgcc` предоставляется пакетом `libgcc1`.
- Добавлено распознавание альтернативных имён зависимостей через `Provides`, включая уже установленные и скачанные пакеты.

## Маршрутизация и диагностика

- Исправлено ложное сообщение об одинаковом прямом IP и IP выхода через VPN при полном проксировании роутера. Проверка прямого IP выполняется вне пользовательских прокси-секций.
- Диапазон IPv6 FakeIP изменён на `2001:2::/112`, чтобы браузеры не воспринимали такие адреса как локальную сеть. Обновлены правила перехвата и исключения прямого TorrServer.

## Дашборд

- Добавлено получение статистики через LuCI, если прямое подключение к API ядра недоступно, в том числе при доступе через Tailscale и HTTPS.
- Выключенные Tailscale и прямой TorrServer больше не отображаются как сервисы с ошибкой. Для включённых, но остановившихся модулей предупреждение сохранено.
- Карточка ядра переименована в «Соединения». Использование памяти отображается только в информации о сервисах.

## Интерфейс

- Добавлены недостающие русские названия и описания глобальной блокировки QUIC и блокировки QUIC для VPN-трафика. Переключение между русским и английским языками сохранено.
