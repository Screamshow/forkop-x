## Установка и обновление

- Исправлена ошибка установки Xrust на OpenWrt 24.10, когда зависимость `libgcc` предоставляется пакетом `libgcc1`.
- Добавлено распознавание альтернативных имён зависимостей через `Provides`, включая уже установленные и скачанные пакеты.

## Маршрутизация и диагностика

- Исправлено ложное сообщение об одинаковом прямом IP и IP выхода через VPN при полном проксировании роутера.
- Диапазон IPv6 FakeIP изменён на `2001:2::/112`.
- Обновлены правила перехвата IPv6 FakeIP и исключения прямого TorrServer.

## Дашборд

- Добавлено получение статистики через LuCI, если прямое подключение к API ядра недоступно, в том числе при доступе через Tailscale и HTTPS.
- Выключенные Tailscale и прямой TorrServer больше не отображаются как сервисы с ошибкой. Для включённых, но остановившихся модулей предупреждение сохранено.
- Карточка ядра переименована в «Соединения». Использование памяти отображается только в информации о сервисах.
