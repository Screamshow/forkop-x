## Переход на Xrust

- Forkop X теперь работает только на Xrust и устанавливает версию ядра из манифеста релиза.
- Для перехода с 2.x на 3.0+ обязательно требуется Forkop X 2.7.6 с ядром Xrust.
- Стандартные пути конфигурации и кэша перенесены в каталоги Xrust с сохранением пользовательских путей.

## Общие изменения

- Проведена чистка кода и оптимизация бэкенда.
- Общие размеры пакетов уменьшены.
- Сокращено число выделений памяти при учёте соединений для Clash API.
- Сокращены повторные чтения кэша подписок.

## Подписки и списки

- Добавлен фоллбек на запрос подписки с sing-box/1.14.2
- Ограничены время загрузки и размер ответа при обновлении и предпросмотре подписок.
- Исправлен предпросмотр подписок после сохранения правок без применения настроек.
- Если источник изменился во время загрузки, устаревший ответ не заменяет кэш подписки.
- Исправлено применение списков маршрутизации с локальными и удалёнными записями.

## LuCI и работа службы

- LuCI показывает теперь только версию Xrust, а диагностика и мониторинг используют новую службу.
- Отложенный автоматический замер задержки повторяется после восстановления Clash API.
