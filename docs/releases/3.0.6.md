## DNS

- При ручной настройке можно выбрать DoH или DoT для основного DNS и UDP для Bootstrap DNS, в том числе на чистой установке.

## Интерфейс

- Выпадающие списки с множественным выбором сохраняют ширину при выборе элементов.

## Ядро

- Xrust обновлён до 0.0.48.
- Ускорение WireGuard и AWG.
- XHTTP stream-up + Reality снижено потребление CPU.
- gRPC TLS/Reality снижено потребление CPU.
- Исправлено перенаправление соединений на локальные сервисы роутера при блокирующих ответах DNS (0.0.0.0 и ::).
