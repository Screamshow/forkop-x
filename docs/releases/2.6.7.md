## DNS

- Добавлена возможность автоматически использовать DNS провайдера, полученные через DHCP или PPPoE, для основного и Bootstrap DNS.
- DNS-запросы направляются через соответствующий WAN-интерфейс с учётом маршрутизации mwan3. Приоритет провайдеров определяется метрикой интерфейса.

## Переключение и восстановление

- Улучшено переключение DNS без перезапуска ядра, если установлен Xrust.
- При ошибке применения или проверки DNS восстанавливается предыдущая конфигурация.
- Настроено восстановление запуска после появления DNS провайдера: временное отсутствие DNS при старте больше не считается постоянной ошибкой конфигурации.

## Мониторинг

- Добавлено резервное получение списка соединений через LuCI, если прямое подключение к API ядра недоступно (Tailscale)

## Диагностика

- Устранены ложные предупреждения о конфликтующих метках для штатных правил встроенного Tailscale.
- Исправлена проверка имён таблиц firewall: посторонние правила в таблицах с похожими именами больше не скрываются из диагностики.
