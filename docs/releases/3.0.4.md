## DNS и маршрутизация

- После прерванного применения настроек Forkop X восстанавливает рабочие правила и снимает временную блокировку трафика.
- Если при остановке Forkop X не удалось восстановить dnsmasq, восстановление повторяется.
- Исправлено применение DNS-правил с исключениями по адресу источника и подключение к DoH по IPv6-адресу.
- Диагностика отдельно проверяет системный DNS и Xrust и показывает ошибку, если все выполненные проверки провалились.
- Bypass с удалённым списком и портом применяется только при совпадении обоих условий.
- Исправлена обработка сложных SRS-правил с исключениями и сочетаниями адресов, портов и протоколов.

## Подписки и списки

- Исправлен импорт серверов после комментариев в Clash YAML.
- Новые списки проверяются в Xrust перед применением, а рабочая версия сохраняется для перезапуска и отката.

## LuCI

- Редактор подписок открывается сразу с сохранёнными значениями и подгружает список серверов в фоне.
- Исправлено отображение больших списков серверов на «Дашборде» и соединений в «Мониторинге» при доступе через HTTPS.
- Если переключить сервер не удалось, «Дашборд» показывает ошибку и отображает фактически активный сервер.
- DNS TTL, регулярные выражения и профили WireGuard проверяются до сохранения.
- В мониторинг для прямых соединений добавлена отдельная вкладка.

## Tailscale и TorrServer

- Отмена удалённой поддержки отзывает доступ, даже если Tailscale не отвечает.
- При сбое переключения SSH, Exit Node или LAN восстанавливается предыдущая настройка, а карточка выходит из состояния «Подключение».
- Отключение TorrServer Direct через LuCI теперь применяется без перезапуска фонового процесса.

## Оптимизации

- Ускорены генерация конфигурации подписок и обработка крупных списков подсетей.
- При проверке неизменных списков обновляется отметка времени без повторной записи содержимого во flash.
- Для проверки DNS используется один локальный слушатель вместо 17.
- LuCI реже запрашивает полное состояние роутера, обновляет только изменившиеся строки мониторинга и не разбирает списки повторно при прокрутке.
- Упрощены проверки готовности служб и обновление кэша.
