## AmneziaWG

- Добавлен режим AmneziaWG для секций «Подключение». Можно вставить или импортировать клиентский `.conf` с одним пиром или профиль WireGuard в JSON.
- Для секции можно задать отдельный DNS-сервер и отправлять запросы к нему через туннель.
- Для работы AmneziaWG требуется Xrust 0.0.36 или новее.

## URLTest

- Исправлены дубликаты узлов при отключённом импорте URLTest-групп из подписки.

## DNS

- При смене DNS через Failover переключение подтверждается после двух успешных проверок подряд.

## Замер задержки

- При массовом замере сохраняются результаты ответивших узлов, даже если часть узлов недоступна.
- Ошибки Clash API теперь учитываются как неудачные замеры.

## Полное удаление

- Полное удаление Forkop X продолжается при ошибке остановки службы. Если групповое удаление пакетов завершилось ошибкой, скрипт повторяет удаление оставшихся пакетов по одному.

## Интерфейс

- Выбор встроенных наборов правил обновлен на checkbox.
- В дашборде добавлена кнопка замера задержки отдельного узла.
