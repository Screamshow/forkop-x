# Forkop X 2.6.0 — описание для обсуждения

Черновик. Публикация не согласована. Canary для этого выпуска пропускается.

Forkop X получает интеграцию очищенного Zapret Manager и установку Xrust на
OpenWrt с архитектурой пакетов `aarch64_generic`, включая Rockchip/ARM64.

- При обновлении Forkop ранее установленный Zapret Manager переводится на
  наш форк. Чистая установка Forkop не устанавливает менеджер автоматически.
  Учитывается источник панели и загрузчиков, а не только номер версии.
- В менеджере остаются Дашборд, Zapret, Zapret2, Hosts и Терминал. У панели
  и консоли общий backend. Для обновлений используются зеркало Forkop и
  резервный источник Screamshow на GitHub.
- Миграция сохраняет настройки панели, стратегии, списки и конфигурацию
  Zapret/Zapret2/Hosts. При ошибке установки или RPC возвращаются прежние
  файлы и загрузчики. Независимые сторонние службы не удаляются.
- Для Rockchip добавлены пакеты Xrust `aarch64_generic`. Поддержаны подбор
  пакета, список доступных версий и проверка совместимости архитектуры.
  Системные зависимости и модули ядра берутся из репозиториев прошивки.

В существующей `dev` также подготовлены ускорение команд через кеш bytecode,
исправления блокировок и тестов задержки, восстановление маршрутизации после
изменений сети, bootstrap DNS для NTP и уточнение показателей служб.

Важное изменение уже подготовленной ветки: встроенные действия правил Zapret
и Zapret2 удалены. При обновлении старые правила отключаются и переводятся
в bypass; связанные с ними недоступные Mixed Proxy и detour очищаются.
Это не перенос стратегий старых правил Forkop в отдельный Zapret Manager:
дальнейшая настройка DPI выполняется в менеджере.

Пакеты и подбор архитектуры проверены; тесты на реальном Rockchip не проводились
из-за отсутствия устройств. Полный набор вариантов прошивок и реальный DPI-трафик
Zapret в эту проверку не входили. Перед выпуском Forkop необходимо опубликовать
согласованные Zapret Manager и Xrust и проверить их публичные адреса на VM.
