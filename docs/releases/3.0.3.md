## Установка и восстановление

- Общий установщик обновляет старые версии Forkop X через 2.7.6, при необходимости самостоятельно переключает sing-box на Xrust и затем устанавливает Forkop X 3.0.3 вместе с закреплённым Xrust 0.0.45.
- При сбое обновления сохраняются модули, которые нужны старому процессу LuCI для отката.
- Установщик сверяет версию и ревизию Xrust с архивом установленного Forkop X. Повторный запуск ремонта освобождает блокировку завершившегося процесса.
- Для перехода со старого Forkop X с sing-box используйте [общий установщик](https://mirror.51343.ru/forkop/install.sh). Он подготовит подходящее ядро до обновления пакетов.

## DNS

- Bootstrap DNS учитывает выбранный транспорт при запуске и обновлении конфигурации.

## Настройки

- Удалён WAN-доступ к YACD. При обновлении удаляются устаревшие параметры WAN-доступа и его ключ, настройка локального YACD сохраняется.
- Обновление списков и проверка компонентов учитывают время, прошедшее с предыдущего запуска, с точностью до минуты. Минимальный интервал составляет одну минуту.
