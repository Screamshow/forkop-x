## Установка и восстановление

- [Общий установщик](https://mirror.51343.ru/forkop/install.sh) обновляет старые версии через 2.7.6 с автоматическим переходом с sing-box на Xrust.
- Ядро обновлено до Xrust 0.0.46.
- Улучшено распознавание BitTorrent.
- `--repair-xrust` восстанавливает версию и ревизию ядра из архива установленного релиза.
- Автоматический ремонт сохраняет остановленное состояние Forkop.
- Ремонт ядра блокирует параллельное обновление из LuCI и запуск службы.
- Исправлен откат после сбоя обновления из LuCI.
- При отказе IPK-обновления из-за отсутствия нативного Xrust восстанавливается состояние службы.

## DNS

- Bootstrap DNS наследует UDP, DoH или DoT, в том числе при резервной загрузке подписок и списков.
- При обновлении существующих настроек DoH и DoT Bootstrap сохраняет UDP до явного выбора общего транспорта.
- Диагностика показывает транспорт Bootstrap DNS.
- Улучшен запуск с DoH и DoT при несинхронизированных часах.
- Восстановлено определение страны серверов со старыми настройками Bootstrap UDP по имени хоста.
- Журнал переключения Bootstrap DoH скрывает путь резолвера.

## LuCI

- В поле «Включить серверы» для URLTest и Priority появились флажки.
- Удалены WAN-доступ к YACD и его ключ.
- Clash API слушает адрес LAN или loopback, если LAN недоступен.
