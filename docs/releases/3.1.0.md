## LuCI

- При выборе устройств в маршрутизации отображаются только адреса из локальных сетей.
- BitTorrent-соединения, направленные напрямую, теперь отображаются во вкладке Direct.
- Уменьшен размер пакета LuCI.

## Память

- Неизменившиеся модули ucode занимают одну копию в кэше при смене его поколения.
- Убрана повторная обработка полного JSON при восстановлении кэша подписок и горячей перезагрузке конфигурации.
