## Запуск и перезапуск

- Кнопка «Перезапустить Forkop X» теперь работает с сохранёнными списками, если их не удалось обновить.
- После неудачного запуска Forkop X повторная попытка может сработать при подключении любого WAN-интерфейса.

## DNS

- В настройках DNS уточнены подписи режимов DoH и DoT.

## ZMS

- Обновление Forkop X сохраняет установленный вариант Zapret Manager и его источник обновлений.
