## Установка и обновление

- На новых установках используется Xrust. Обновление существующей установки сохраняет выбранное ядро.
- Добавлен выбор версии Xrust из каталога зеркала, включая установку предыдущих версий.
- Добавлена поддержка Beam WRT и выбора пакетов ARM64 Cortex-A73.
- Необходимые зависимости устанавливаются до остановки Forkop. Убрана отдельная зависимость от пакета flock.
- Обновлено переключение репозиториев OpenWrt на зеркало. Если замена невозможна, сохраняются штатные репозитории, в том числе в BeamWRT.
- Убрана установка Sing-Box Extended через встроенный установщик. Сохранена совместимость с ранее установленными и ручными сборками.

## Подписки и протоколы

- Разрешены подписки от любых провайдеров.
- Добавлена поддержка Trojan в Xrust при наличии соответствующей возможности в ядре. Ссылки Trojan без параметра security используют TLS.
- Узлы с протоколами, отсутствующими в установленном Xrust, исключаются при формировании конфигурации.
- Неподдерживаемые VLESS Encryption и REALITY pqv больше не отбрасываются молча. Несовместимые узлы пропускаются либо отклоняются с ошибкой.
- Сохранена передача отпечатка сертификата Hysteria2 pinSHA256 в конфигурацию ядра.
- Профили uTLS android, 360 и qq заменяются на firefox при работе с Xrust.

## Применение настроек

- Ускорено планирование горячей перезагрузки Xrust без повторного разбора содержимого наборов правил.
- При горячей перезагрузке с прежней сетевой политикой исключено лишнее переключение правил nftables.
- Уменьшено количество вспомогательных процессов при ожидании применения конфигурации.
- Исправлена передача токена Clash API при заданном секрете.
- Ожидание запуска компонента завершается сразу после окончательной ошибки запуска.

## TorrServer Direct

- Исправлена работа TorrServer Direct с FakeIP. Соединения к FakeIP-адресам IPv4 и IPv6 проходят через ядро Forkop, а соединения с пирами по реальным IP остаются прямыми.
- Устаревшие правила TorrServer Direct без исключений FakeIP автоматически заменяются.
- При обновлении Forkop служба TorrServer Direct перезапускается для применения изменений, если этот режим включён.

## Компоненты

- Удалена поддержка ByeDPI. При обновлении очищаются связанные правила и настройки.
- При установке Zapret-Manager включается его веб-интерфейс.
- Обновлено полное удаление Forkop X.

## Интерфейс и внутренняя оптимизация

- Из выбора языка Forkop X удалён вариант «Как в LuCI».
- Уменьшен размер JavaScript интерфейса за счёт сохранения кириллицы в UTF-8.
- Удалены неиспользуемые внутренние обработчики и вспомогательные функции backend.
- Проверки возможностей встроенного Tailscale кэшируются для запросов состояния LuCI.
