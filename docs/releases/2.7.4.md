## Подписки и выбор серверов

- Добавлена автоматическая загрузка списка серверов при редактировании источников подписки, до сохранения и применения настроек.
- Серверы из загруженного списка доступны для выбора в фильтрах URLTest и уровнях Priority.
- Исправлено появление скрытых технических имён рядом с выбранными серверами. При обновлении подписки сохраняются видимые имена, а ранее добавленные скрытые дубликаты удаляются из выбора.

## Hysteria 2

- Исправлено добавление вручную ссылок с переключением портов: поддерживаются списки и диапазоны портов, в том числе через параметр `mport`.

## DNS и уведомления

- Уведомление об отказе DNS появляется только после нескольких последовательных проверок, подтвердивших недоступность всех основных DNS-серверов.
- Устранены лишние уведомления об ошибках при переключении DNS и восстановлении предыдущей конфигурации. Промежуточные сбои сохраняются в журнале как предупреждения.

## Установка и диагностика

- При обновлении Forkop X через установочный скрипт теперь также обновляется уже установленный Xrust.
- Исправлена проверка правила маршрутизации для проверки источника на OpenWrt с разными реализациями команды `ip`.
